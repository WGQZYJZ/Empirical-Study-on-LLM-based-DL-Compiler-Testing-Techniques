
class Model(torch.nn.Module):
    def __init__(self):
        super().__init__()
        self.linear = torch.nn.Linear(3, 10)

    def forward(self, x):
        l1 = self.linear(x)
        # clamp is only necessary for SELU because max(x, min=0), the max value of a value x, which has a value of 6 (max=3*3*6+0=7).
        l2 = clamp(l1 + 3, l1 * 6, l1 / 6)
        return l2
```
# Initialization and Forward Passing
A PyTorch model can be initialized with the parameters defined in its constructor. To do so, we can use a simple forward pass to evaluate the output of a given input tensor.
```
