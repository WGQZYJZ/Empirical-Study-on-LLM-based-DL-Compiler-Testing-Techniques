
class Model(torch.nn.Module):
    def __init__(self):
        super().__init__()
        self.linear = torch.nn.Linear(2, 2)

    def forward(self, x1):
        v1  = x1.permute(0, 2, 1)
        v2 = torch.nn.functional.linear(v1, self.linear.weight, self.linear.bias)
        return v2
```
This pattern characterizes scenarios where the input tensor is first swapped to become the output tensor of a linear function application, and then it's permute method is invoked on this swapped output with more than 2 dimensions.
