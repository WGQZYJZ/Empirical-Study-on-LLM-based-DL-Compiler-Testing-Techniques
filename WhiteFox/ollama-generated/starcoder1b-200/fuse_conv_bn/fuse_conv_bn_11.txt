class Model(torch.nn.Module):
    def __init__(self):
        super().__init__()
        self.conv = torch.nn.Conv2d(...)
        self.bn   = torch.nn.BatchNorm2d(...)

    def forward(self, x1, x2):
        v1 = self.conv(x1)
        v2 = self.bn(v1)
        return torch.cat([v1, x2], 1), self.conv(x2)
```
This pattern characterizes scenarios where the two convolutions are in evaluation mode (not in training mode), followed by a batch normalization layer on them and then they are fused into a single convolution layer, followed by a batch normalization layer on the concatenated output of both. If the input to the conv layer is used by other nodes, the optimization will not be performed.


# Model
class Model(torch.nn.Module):
    def __init__(self):
        super().__init__()
        self.conv = torch.nn.Conv2d(...)
        self.bn   = torch.nn.BatchNorm2d(...)

    def forward(self, x1, x2):
        v1 = self.conv(x1)
        v2 = self.bn(v1)
        return v2 + torch.mean(v2, dim=[0]), self.conv(x2)
```
This pattern characterizes scenarios where the two convolutions and batch normalization layers are in evaluation mode (not in training mode), followed by a single batch normalization layer on them and then the conv layers are fused together with a batch norm layer on their concatenated output. If the input to the conv layer is used by other nodes, the optimization will not be performed.
