
class Model(torch.nn.Module):
    def __init__(self):
        super().__init__()
        self.linear = torch.nn.Linear(2, 2)

    def forward(self, x1):
        v1 = x1.permute(0, 2, 1)
        v2 = torch.nn.functional.conv2d(v1, self.linear.weight, self.linear.bias) # X can be 3 representing the dimension
        return v2
```
This pattern characterizes scenarios where a convolution layer (`torch.nn.functional.conv2d`) is followed by a batch normalization layer (`torch.nn.functional.batch_norm`). The output of the convolution layer is used as the input to the batch normalization layer.
