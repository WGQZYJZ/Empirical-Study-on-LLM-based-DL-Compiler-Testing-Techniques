```
return torch.matmul(attn, value)  # Compute the weighted sum between query and key
```
This pattern characterizes scenarios where the attention weights are computed as the softmax of the scaled dot product of the query and key. The output is then scaled down by using the attention weights and then a dropout operation to reduce the dimensionality of the scaled dot product (e.g. if `query = [1, 2]` and `key = [[0, 0], [1, 1]]`, then the scaled dot product is `[[0, 0], [0, 0], [1, 1]]`. The weighted sum of these two components is then added to the output.
