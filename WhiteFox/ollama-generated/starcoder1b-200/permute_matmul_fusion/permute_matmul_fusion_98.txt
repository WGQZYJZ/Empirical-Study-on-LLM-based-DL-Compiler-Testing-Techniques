
class Model(torch.nn.Module):
    def __init__(self):
        super().__init__()
        self.bmm = torch.nn.Bilinear(2, 2, 3)

    def forward(self, x1, x2):
        v1 = x1.permute(0, 2, 1)
        v2 = torch.nn.functional.linear(v1, self.bmm.weight, self.bmm.bias)
        return v2


# Initializing the model
m = Model()


# Inputs to the model
x1 = torch.randn(1, 2, 2)
y1 = torch.randn(1, 3, 3)
__output_a = m(x1, y1)
__output_b = m(y1, x1)


# Description of requirements
The model should contain the following pattern:
```
t1 = input_tensor_A.permute(...)  # Permute the input tensor A
t2 = input_tensor_B.permute(...)  # Permute the input tensor B
t3 = torch.bmm(t1, t2)  # or torch.matmul(t1, t2)
```
or
```
t1 = input_tensor_A.permute(...)  # Permute the input tensor A
t2 = input_tensor_B.permute(...)  # Permute the input tensor B
t3 = torch.bmm(input_tensor_A, t1)  # or torch.matmul(input_tensor_A, t1)
```
or
```
t1 = input_tensor_B.permute(...)  # Permute the input tensor B
t2 = input_tensor_A.permute(...)  # Permute the input tensor A
t3 = torch.bmm(input_tensor_B, t2)  # or torch.matmul(input_tensor_B, t2)
```
This pattern characterizes scenarios where the tensor method  'permute' is invoked on one input tensor and then the `torch.bmm` or `torch.matmul` function is invoked on the permuted tensors. The permute method is invoked on an input tensor with more than 2 dimensions, and it swaps the last two dimensions of this tensor. This modified tensor is then used as the main input for the `torch.bmm` or `torch.matmul` function.

# Test cases
## Input tensor (1 x 3 x 5)
* Case 1: Input tensor has more than 2 dimensions, and it swaps the last two dimensions of this tensor, that is, t1 = [t1_0 t1_1 t1_2] and t2 = [t2_0 t2_1 t2_2], respectively. The modified tensor will be
t3 = [t3_0 t3_1 t3_2].
* Case 2: Input tensor has more than 2 dimensions, but the last two dimensions of both input tensors are swapped, i.e., the swapping can't be used to achieve the target output.
* Case 3: All input tensors have more than 2 dimensions and all the dimension values are not same.
