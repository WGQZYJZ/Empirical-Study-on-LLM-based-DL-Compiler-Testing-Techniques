
class Model(torch.nn.Module):
    def __init__(self, min_value=0., max_value=1.):
        super().__init__()
        self.linear = torch.nn.Linear(3, 8)
 
    def forward(self, x):
        return self.linear(x) * torch.clamp((torch.randn(*x.shape[1:]), -max_value, max_value), -min_value, min_value)
```
# Description of requirements
The model should contain the following pattern:
```
t1 = linear(input_tensor)  # Apply a linear transformation to the input tensor
t2 = t1 * 0.5  # Multiply the output of the previous operation by 0.5
```
This pattern characterizes scenarios where the output of the linear transformation is multiplied by `0.5`, and then the result is returned.
```
