
class Model(torch.nn.Module):
    def __init__(self):
        super().__init__()

    def forward(self, x1, x2):
        v1 = x1.permute(0, 2, 1) # Permute the input tensor A
        v2 = x2.permute(0, 2, 1) # Permute the input tensor B
        v3 = torch.bmm(v1, v2) # or torch.matmul(v1, v2)
        return v3
```

Inputs to the model must be different. Otherwise, it may lead to non-differentiable behavior when using gradient based optimization methods such as SGD and Adam for training a neural network model.
