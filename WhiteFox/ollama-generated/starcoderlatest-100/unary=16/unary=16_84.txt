## Description: 278, 356, 452, 538.192 sats per vbyte processed, fees calculated by nodes that own the UTXOs used in these transactions; fee is always smaller than or equal to a set value, but larger than zero

## Solution:

1、Create some empty files for saving all generated data and the result of the simulation results。

2、Set up the environment with `nvm`, then create an object called `node1` and call it with:

    ```
    let node1 = new Node(); //set initial values to properties
    node1.init("localhost", "3001", null); //localHost, port, password, here is set as null, this means there will be no password
    ```

3、For a better understanding of the code, you can take a look at `src/node.js`. The following table lists all methods of `Node` class and their corresponding operations:

    | method name       | description     |
    |:-----------------:|:---------------:|
    | `init()`          | set up the node|
    | `getBlockchain()` | get all blocks from chain data    |
    | `getBlockChainInfo()` |get block info(index,hash) in a specified range      |
    | `getBlockAt`   |return block with the index specified by parameter       |
    | `getMinedTxListForCoinbaseAddressByBlockIndex`     | 1: get txList of all mined transactions for coinbase address in a specific block    |
    | `getMinedTxCountForCoinbaseAddressByBlockIndex`        |2:get number of mined transaction for coinbase address in a specific block     |
    | `getTransactionInfo(txHash)`|3: get tx's info in the chain data with the tx hash   |
    | `addUTXOToUtxoList()`      |4: add utxo object to Utxo list       |
    | `getCoinbaseTransactionForAddress(address)` | 5: return coinbase transaction with the address     |

    The basic operations are as follows:

- Step1: `node.init()`: It mainly used for setting up nodes by creating a new `Node` object, and set up the initial properties to it. The following two attributes are the only two needed attributes of this class:

    - ipaddress
    - portnumber

    > Note that you can get these data from your node list.

- Step2: `node.getBlockChain()`: This is mainly used for retrieving block information, and add this info to an object named `blockchain`. And when the result will be saved into a file in step3.

- Step3: `node.minedTxListForCoinbaseAddressByBlockIndex(blockIndex)`：This method will return the list of mined transactions for coinbase address in the block with the specified index. To do that, it first needs to get the block hash in order to know which one is corresponding to the block with specified index.

    After getting the block's hash, the function `getBlockChainInfo()` can be used to get all block info from chain data with the block hash.

- Step4: `node.minedTxCountForCoinbaseAddressByBlockIndex(blockIndex)`：This method will return number of mined transaction for coinbase address in the block with the specified index. It firstly needs to know which one is corresponding to the block with specified index. Then it can get info from chain data and get all transactions' info in the chain data and count how many txs in the list contains this address.

- Step5: `node.transactionInfo(txHash)`：This method will return tx's info in the chain data with the hash of specified transaction. The information is used to check if the utxo object corresponding to the input is owned by specified address or not.
