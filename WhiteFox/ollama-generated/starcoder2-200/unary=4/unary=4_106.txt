
class Model(torch.nn.Module):
    def __init__(self):
        super().__init__()
        self.linear  = torch.nn.Linear(2, 10)
 
    def forward(self, x1):
        v1 = self.linear(x1)
        v2  = v1 * 0.5 
        v3  = v1  * 0.7071067811865476
        v4  = torch.erf(v3)
        v5  = v4 + 1
        v6  = v2  * v5
        return v6


# Initializing the model
m = Model()
# Inputs to the model
x1 = torch.randn(8, 2)
__output__  = m(x1)
```

# Description of requirements
The model should contain the following pattern:
```
t1 = linear(input_tensor)  # Apply pointwise linear transformation to the input tensor
t2 = t1 * 0.5  # Multiply the output of the linear transformation by 0.5
t3 = t1  * 0.7071067811865476  #Multiply the output of the linear transformation by another constant `0.7071067811865476` and then `1` is added to it
```
This pattern characterizes scenarios where the output of a pointwise linear transformation is multiplied by a constant `0.5`.
