# Description of requirements
The model should contain the following pattern:
```
t0_input   = input_tensor  # Assigns an initial input value to an intermediate variable
t1    = conv(t0)          # Apply pointwise convolution with kernel size 3 to a variable that contains the input tensor for this layer.
t2     = t1 - t0          # Subtract the output of the convolution from another variable, which contains the initial input value.
```
This pattern characterizes scenarios where the initial input value is assigned as an intermediate variable in the forward pass and then a pointwise convolution operation is performed on that variable to produce its output. The output of the convolution is then subtracted from a variable that contains the initial input value, effectively performing a 3-point difference.
