
```python
class Model(torch.nn.Module):
    def __init__(self):
        super().__init__()
        self.lin = torch.nn.Linear(28, 1)

    def forward(self, x1): 
        v1 = self.lin(x1).sum() + 3 # linear transformation
        return v1
```

m = Model().cuda()
