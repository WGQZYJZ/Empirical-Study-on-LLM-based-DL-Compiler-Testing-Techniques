```
t2 = torch.bmm(input_tensorB, t1)  # or torch.matmul(input_tensorB, t2) 
```
The permute method is invoked on an input tensor with more than 2 dimensions, and it swaps the last two dimensions of this tensor. This modified tensor is then used as the main input for the `torch.bmm` or `torch.matmul` function.
