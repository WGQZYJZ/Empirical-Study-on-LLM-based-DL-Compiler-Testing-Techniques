The model should contain the following pattern:
```
t1 = input1 + 0.9 # Add 0.9 to an input tensor. 'input1' is a keyword argument that accepts an input tensor as its value. The 'input1' parameter does not have a default value.
t2 = input1 - 3  # Subtract 3 from the result of the previous operation.
```

 This pattern characterizes scenarios where you need to perform mathematical operations on one tensor and then another mathematical operation is performed on that first tensor. 
 The first mathematical operation adds '0.9' to an input tensor, and the second mathematical operation subtracts 3 from this value.
