
```python
class Model(torch.nn.Module):
    def __init__(self):
        super().__init__()
        self.linear  = torch.nn.Linear(10, 8)
        self.sigmoid = torch.nn.Sigmoid()
 
    def forward(self, x2):
        v1  = self.linear(x2)
        v3  = v1 * self.sigmoid(v1)
        return v3
```
