
class Model(torch.nn.Module):
    def __init__(self):
        super().__init__()
        self.linear1 = torch.nn.Linear(48, 20)
 
    def forward(self, x1):
        v1 = self.linear1(x1)
        v2 = v1 - 5 
        return v2

# Description of requirements
The model should contain the following pattern:
```
t1 = torch.max(input_tensor) * other # Multiply 'other' by the output of the max function applied to an input tensor.
```
This pattern characterizes scenarios where a scalar (referred to as 'other') is multiplied by the output of the max function that applies to an input tensor, and then is stored in a new variable named `t1`.
