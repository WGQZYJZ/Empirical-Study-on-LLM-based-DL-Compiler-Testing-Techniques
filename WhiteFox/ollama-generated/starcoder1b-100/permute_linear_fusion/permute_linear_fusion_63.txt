
class Model(torch.nn.Module):
    def __init__(self):
        super().__init__()
        self.linear = torch.nn.Linear(2, 2)

    def forward(self, x1):
        v1 = x1.permute(0, 2, 1)
        v2 = torch.nn.functional.linear(v1, self.linear.weight, self.linear.bias)
        return v2
```

## Usage
Run `python3 main.py` to run the main file and input a valid PyTorch model example. The inputs must be in the following format: 3D tensor (NxHxW), 4D Tensor (BxCxHxWx), or 5D Tensor (BxNxMxHxDy).
