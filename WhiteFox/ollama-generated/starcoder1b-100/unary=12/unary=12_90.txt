# Description of requirements
The model should contain the following pattern:
```
t1  = conv(input_tensor) # Apply pointwise convolution with kernel size 1 to the input tensor
t2  = relu(t1 * 0.5) # Apply a relu function, where the argument is multiplied by 0.5 (and then passed through a sigmoid activation function)
```
This pattern characterizes scenarios where the output of a pointwise convolution is applied to `relu` and passed through a sigmoid function. This pattern enables the information flow through a gating mechanism in many use cases, including deep learning applications such as image classification, speech recognition, and natural language processing (NLP).
