
class Model(torch.nn.Module):
    def __init__(self, negative_slope):
        super().__init__()
        self.linear  = torch.nn.Linear(3, 8)
        self.negative_slope  = negative_slope
 
    def forward(self, x1):
        v1 = self.linear(x1)
        v2 = (v1 > 0).float()
        v3 = v1 * self.negative_slope
        return torch.where(v2, x1, v3)


# Initializing the model
m = Model(negative_slope=0.1)
```
# Description of requirements
The model should contain the following pattern:
```
t1 = relu(input_tensor)  # Apply a rectified linear unit function to the input tensor
t2 = t1 * alpha  # Scale the output of the rectified linear unit function by `alpha`
```
This pattern characterizes scenarios where the output of the rectified linear unit function is scaled by an alpha factor. This is the most common form of Leaky ReLU activation function, which allows a function to take negative value as input (zero-valued output) if the corresponding element in the input tensor is less than zero and positive value otherwise.
