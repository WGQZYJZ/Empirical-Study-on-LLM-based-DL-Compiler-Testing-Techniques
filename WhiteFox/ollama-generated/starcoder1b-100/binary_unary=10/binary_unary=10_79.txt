# Description of requirements
The model should contain the following pattern:
```
t1 = f(input_tensor) # Apply a function to input tensor
t2 = t1 + other  # Add another tensor to the output of the function
t3 = t2 * scalar  # Multiply the output of the function by `scalar`
```
This pattern characterizes scenarios where a function is applied to an input tensor, then another tensor is added to the output of the function, and finally the result of this operation is multiplied by `scalar`. The function should not be dependent on other inputs.
