
class Model(torch.nn.Module):
    def __init__(self):
        super().__init__()

    @torch.jit.script_method
    def forward(x1):
        ...

    @torch.jit.script_method
    def rand_like(x2, eps=0.0):
        # Here 'eps' is a placeholder for the value that the replacement function will replace it with

        with torch.no_grad():
            return torch.rand_like(x1) * eps
```
In this pattern, we use `@torch.jit.script_method` to decorate `forward` and `rand_like`. The first `@torch.jit.script_method` line marks the beginning of a scriptable function (for example: `model.forward`). In this case, we're annotating a line with `@torch.jit.script_method`, which indicates that the function to be annotated has no side effect when executed through Python. The `@torch.jit.script_method` tells PyTorch that these functions will not trigger replacements or erasure of the graph after execution through the `gm.graph.erase_node(node)` line, which is triggered in `__init__()` above. Since this model contains a dropout layer in its forward pass (a `t1 = ...  # Permute input` node), the `torch.no_grad()` decorator on `forward` does not trigger replacement or erasure of the graph.
