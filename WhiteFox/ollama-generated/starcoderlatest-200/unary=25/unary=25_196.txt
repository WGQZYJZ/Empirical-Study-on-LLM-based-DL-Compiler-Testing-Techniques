
class Model(torch.nn.Module):
    def __init__(self):
        super().__init__()
        self.conv = torch.nn.Linear(64, 32)
 
    def forward(self, x1):
        v1 = self.conv(x1)
        v2 = torch.where(v1 > 0, v1, -self.conv.negative_slope * v1)
        return v2


# Initializing the model
m = Model()
```
The output of the linear transformation is multiplied by a negative slope and then applied as an input to another linear transformation where the negative slope is `0.05`. The output of the first linear transformation after applying the Leaky ReLU activation function is subtracted from the output of the second linear transformation.
```
